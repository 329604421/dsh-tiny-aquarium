## 6. 未实测与已知限制

1. **Desktop Electron 外壳**：Windows 下 `--dsh-windows-sidebar-width` 与 `--dsh-frame-chrome-top` 的实际取值、标题栏拖动、真实最小化、GPU 显存占用未在本轮取得；代码仅使用公开变量，无宿主 DOM 读取。
2. **设置弹层层级**：P1 未注册 `settings.section`；打开设置弹层时鱼缸被覆盖属宿主行为，待 P3 联调时复核。
3. **任务共存**：隔离 Web 宿主未登录，未执行智能体任务；遮罩不暂停也不读取任务。
4. **性能结论边界**：60 FPS 为 Web 宿主 headless 实测；未替换为 Desktop 固定设备正式基线，也未读取 GPU 进程显存。
5. **素材**：P1 缸体、灯具、底砂、气泡均为程序化几何；`.glb` 内联素材管线与回退在 P2 首条鱼落地时实现。当前 `presets.json` 只登记 2 个程序化预设。
6. **交互范围**：鼠标优先；无音效、触屏、缩放、垂直旋转；不保存鱼（尚无）与残余鱼食。
7. **分块命名差异（重要）**：宿主只接受 `client.<name>.js` 形式的同级 chunk（`CLIENT_CHUNK` 正则），不能用需求文档示例中的 `model-<id>.js`。本项目已改用 `client.scene.js` 并在注册时声明 `chunk`。

## 7. 给 P2 的能力契约

| 能力 | 现有实现 | P2 接入点 |
| --- | --- | --- |
| 坐标与空间 | 缸体局部坐标，米制；`SPACE = {width .40, height .30, depth .25, waterY .267, floorY .018}`；内壁边界 `x ±.193`、`z ±.118`；`yaw` 只作用于缸体组 | 鱼在同一局部空间游动；转动不改变鱼与食物的相对关系 |
| 敲击事件 | `sim.tap(point, normal, now)` → 冻结的 `{point, normal, time, intensity}`；300 ms 节流；`scene.onTap(listener)` 返回取消函数 | 按距离与品种参数触发避让与恢复，不重复实现输入 |
| 食物集合 | `{id, state, age, alpha, x, y, z, radius, speed, phase}`；`getFood()` 返回副本；`consumeFood(id)` 原子消费一次；硬上限 100 | 鱼查询、选目标、到达后消费；失效目标重新选择 |
| 模拟生命周期 | 固定 60 Hz，单帧最多补 3 步；隐藏/不可见暂停；`dispose()` 释放 RAII 资源 | 鱼群与骨骼动画加入同一时钟；关闭时统一清理 |
| 素材清单 | `presets.json`（`category`/`version`/`file`/`displayName`/`bounds`(cm)/`anchor`/`forward`/`license`） | 增加 `fish.*` 条目与 `Swim` 动画；未知 id 回退默认并提示 |
| 配置 | `schemaVersion 1`，全部 volatile；缺失鱼字段合法 | 升级至 `schemaVersion 2`，填充已验收默认鱼种，不把无鱼判为损坏 |

## 9. 2026-11-17 界面改版（P1.1）

前 8 节记录的是改版前的单入口实现；改版把玩法入口与设置入口拆开，并补上了悬浮层缺失的遮罩。

| 变化 | 改版前 | 改版后 |
| --- | --- | --- |
| 玩法入口 | 悬浮按钮 + `shell.overlay` 整框遮罩 | 保留：`shell.overlay`（`id: eco-aquarium-view`，`order: -100`），入口按钮位置不变 |
| 遮罩 | 仅 5%–19% 的径向渐变，页面正文直接透过玻璃 | 深色半透明底（浅色 `rgba(23,41,32,.54)` / 深色 `rgba(3,9,6,.72)`）+ `backdrop-filter: blur(20px)`，正文变成柔和底色，玻璃缸保住对比度 |
| 设置入口 | 无 | 新增 `sidebar.panellist` 一行（`order: 40`）+ `main` 页面（`key: eco-aquarium`） |
| 设置页内容 | 悬浮层里的画质下拉 | 场景 / 造景与生物 / 显示与光照 / 看鱼缸四块；P2、P3 项标注「即将开放」并禁用 |
| 取景 | 贴近缸体的特写，缸体被视口裁切 | 相机拉远并上移焦点，缸体、灯具、底砂阴影完整落在视图内 |
| 操作栏 | 底部居中横排 | 左侧中部竖排（灯光 / 鱼食 / 画质 / 倍率）；画布改为铺满窗口，底部只留提示行，不再有空遮罩带 |
| 缩放 | 无 | 滚轮或 `+` `-` 在 1.0×–2.2× 之间缩放；超过边界后画面沿圆形遮罩模糊收边 |
| 小图标 | 32px 悬浮按钮图标，另无导航图标 | 24 视网格重绘：缸体 + 水面 + 夹灯 + 颗粒，`currentColor`，导航栏 18px |
| `Esc` | 两级：退出投喂 → 关闭整框 | 不变 |

因此第 3 节第 1、3、9、10、17 项与第 6 节第 1 条（遮罩定位变量）需要按新实现复核；`--dsh-windows-sidebar-width` / `--dsh-frame-chrome-top` 仍在使用。
