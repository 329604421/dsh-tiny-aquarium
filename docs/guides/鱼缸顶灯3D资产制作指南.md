## 0. 先理解这盏灯在做什么

这盏顶灯不是“一个会发光的模型”，而是四个相互配合的部分：

1. **灯体网格**：灯杆、灯臂、灯头、灯管，负责外形；
2. **灯管自发光**：`bulbMat.emissiveIntensity`，负责“看起来灯亮着”；
3. **真实照明**：`THREE.SpotLight`，负责照亮水面、底砂和鱼；
4. **可见光域**：`beamMat` 的透明几何，负责空气/水体中那层柔和的光束。

此外还有第五个隐性部分：**灯光状态机**。深色主题自动开灯、手动关闭优先、亮度平滑过渡，这些都通过每帧的 `light` 变量驱动。

替换灯具时最容易犯的错误，是只做了一个漂亮的灯壳，却把自发光、聚光灯、光域或状态接线丢了。结果就是：模型像灯，但场景不亮，或者长条灯下面出现一个射灯式圆锥。

## 1. 当前顶灯的结构与参数

### 1.1 当前灯型

当前预设是 `lamp.arch`：一根后侧立柱、向前伸出的横臂、悬在水面上方的长条灯头。它挂在 `tank` 组下，所以鱼缸旋转时灯会一起旋转。

| 部件 | 几何/尺寸（米） | 位置（局部坐标） | 作用 |
| --- | --- | --- | --- |
| 立柱 | `CylinderGeometry`，半径约 `0.003`，高 `0.368` | `(0.15, 0.184, -0.146)` | 从缸后侧立起 |
| 横臂 | 盒体 `0.006 × 0.006 × 0.17` | `(0.15, 0.366, -0.065)` | 从立柱伸向灯头 |
| 灯头 | `RoundedBoxGeometry` `0.242 × 0.009 × 0.036` | `(0.035, 0.366, 0.018)` | 长条灯的外壳 |
| 灯管 | 盒体 `0.227 × 0.002 × 0.028` | `(0.035, 0.360, 0.018)` | 自发光面 |
| 聚光灯 | `SpotLight` | 位置 `(0.035, 0.351, 0.018)`，目标 `(0, 0.05, 0)` | 实际照明与阴影 |
| 可见光域 | 四边截锥，见第 6 节 | 中心 `(0.035, 0.201, 0.018)` | 柔和的长条光束 |

灯头位于水面上方约 `0.09 m`，聚光灯照向水面下方的 `y = 0.05`，形成从上往下的光池和底部焦散。

### 1.2 当前灯光状态

```js
light += ((lightTarget ? 1 : 0) - light) * 0.13;

spot.intensity = light * 0.44;
bulbMat.emissiveIntensity = 0.08 + light * 2.6;
beamMat.uniforms.strength.value = light * (dark ? 0.85 : 0.28);
causticMat.uniforms.uTime.value = sim.time;
causticMat.uniforms.uStrength.value =
  ((dark ? 0.12 : 0.22) + light * (dark ? 0.85 : 0.48)) * (eco() ? 0.65 : 1);
```

| 变量 | 含义 | 不要丢的原因 |
| --- | --- | --- |
| `lightTarget` | 目标状态（开/关） | 决定自动/手动逻辑 |
| `light` | 平滑后的当前亮度 `0–1` | 所有灯光参数共用，避免跳变 |
| `dark` | 当前是否深色主题 | 控制光域和焦散的强弱 |
| `spot` | 真实照明 | 灯壳亮不代表场景亮 |
| `bulbMat` | 灯管自发光 | 近看时的“亮灯”感 |
| `beamMat` | 可见光域 | 空气中的光束轮廓 |
| `causticMat` | 水面投射到底砂的光斑 | 水波照射感的核心 |

### 1.3 灯与鱼缸的关系

```text
tank (Group，绕 Y 轴旋转)
├─ 鱼缸玻璃/水面/底砂
├─ lampStem / lampArm / lampTop / bulb
├─ spot + spot.target
└─ beamMesh
```

灯必须和鱼缸一起旋转，因为它是“缸的灯”，不是“房间的灯”。如果把灯挂在 `scene` 根节点，旋转鱼缸时灯不会跟着走，光域会横向错位，灯架也会看起来悬空。

## 2. 哪些可以改，哪些必须保留

### 2.1 可以自由改

- 灯的外形：长条灯、圆管灯、方形吊灯、夹灯、双头灯、轨道灯；
- 灯架形式：后立柱、侧夹、吊线、龙门架、壁挂；
- 灯的材质：黑色铝、拉丝金属、白色塑料、木质、黄铜；
- 灯管数量与长度；
- 灯头高度、前后位置、俯仰角；
- 光色：暖白、中性白、冷白（需同步调灯管和聚光灯颜色）；
- 光域宽度、长度、透明度和衰减曲线；
- 是否加灯罩、格栅、柔光板。

### 2.2 必须保留

| 契约 | 当前实现 | 丢失后的表现 |
| --- | --- | --- |
| 灯挂在 `tank` 下 | `tank.add(...)` | 旋转鱼缸时灯不跟着转 |
| 一个随时间平滑的 `light` 值 | `light += ...` | 开灯/关灯跳变，或深色不自动亮 |
| 真实照明源 | `SpotLight` + `spot.target` | 只有灯管发光，底砂/鱼不亮 |
| 灯管自发光 | `bulbMat.emissiveIntensity` | 灯管像一条灰塑料 |
| 可见光域 | `beamMat` + `beamGeo` | 缺少空气光束，或只剩一个圆锥 |
| 光域形状匹配灯体 | 长条灯用长条截锥 | 长条灯下面出现三角形射灯锥 |
| 焦散时间与强度 | `causticMat.uniforms` | 水面有波纹，但底部光照是死的 |
| 资源释放 | `own(...)` / `dispose()` | 反复开关插件后 GPU 资源增长 |
| 交互遮挡/命中 | `userData.kind = 'lamp'` | 点击灯时误触玻璃或水面 |

### 2.3 不建议的做法

1. **用一盏 `PointLight` 代替整个灯条**：点光会让长条灯的光池变成圆形，失去长条灯的方向性。
2. **给长条灯继续用 `ConeGeometry` 光束**：圆锥的顶点在灯头中心，视觉上必然出现三角形入射线。
3. **让灯管自发光代替真实照明**：自发光只影响灯管自身，不会照亮场景。
4. **把灯放在 `scene` 而不是 `tank`**：旋转时灯和缸分离。
5. **只做一个发光面，不建灯架**：近景会像一块漂浮的亮片。

## 3. 先选灯具类型

不同灯型对应不同的光域形状和照明策略。先选类型，再建模。

| 灯型 | 灯体特征 | 推荐照明 | 推荐可见光域 | 注意 |
| --- | --- | --- | --- | --- |
| 长条吊灯 | 一根细长灯头，横向覆盖缸面 | 1 个聚光灯，或 2–3 个并排聚光灯 | 长条四边截锥 | 光域宽度要跟灯管长度一致 |
| 单头射灯 | 小圆头/方头，集中照一个区域 | 1 个聚光灯 | 小截锥或不吃可见光域 | 适合小缸、造景重点照明 |
| 双头灯 | 两个独立灯头 | 2 个聚光灯，各自 target | 每个灯头一束光域 | 两束重叠处容易过曝 |
| 圆管灯 | 圆柱形灯管 | 1 个聚光灯 + 灯管自发光 | 扁圆柱/长条截锥 | 圆柱灯管不要做方形光域 |
| 夹灯 | 小灯头夹在缸沿 | 1 个聚光灯 | 小范围柔和光域 | 夹口不能穿进水面 |
| 轨道灯 | 多灯头沿轨道移动 | 每个灯头 1 个聚光灯 | 每头独立光域 | 控制总强度，避免叠加过亮 |

当前版本推荐优先做**长条灯**，因为缸体是长条缸，长条灯的光域和缸面比例最自然。

## 4. 坐标、挂点与灯头朝向

### 4.1 使用鱼缸局部坐标

灯的所有位置都应写成 `tank` 的局部坐标，单位米：

```text
X：鱼缸宽度方向（左右）
Y：高度（向上）
Z：鱼缸深度方向（前正、后负）
```

当前灯在 `x = 0.035`，略偏右；立柱在 `z = -0.146`，位于缸后侧；灯头在 `z = 0.018`，位于水面上方偏前。这个偏移不是必须的，但换灯时要保证灯头覆盖缸面的主要区域。

### 4.2 先定三个锚点

不要先做灯壳再猜位置。先在鱼缸局部坐标里定：

```js
const LAMP = {
  mount: { x: 0.15, y: 0.184, z: -0.146 },  // 立柱落点
  armY: 0.366,                              // 横臂高度
  head: { x: 0.035, y: 0.366, z: 0.018 },   // 灯头中心
  sourceY: 0.351,                           // 实际发光面高度
  target: { x: 0, y: 0.05, z: 0 },          // 照向水面下方
};
```

- `mount` 应落在缸后壁或缸沿上，不能悬空；
- `head` 要在水面上方，通常高出缸口 5–10 cm；
- `sourceY` 是灯管下表面，不是灯头中心；
- `target` 不要设在水面正上方，否则光只会照到水面，不会形成缸内光池；当前目标是水面下方的 `y = 0.05`。

### 4.3 灯头朝向

- 长条灯的灯管长轴默认沿 X；
- 如果灯头旋转，光域也必须同步旋转，不能只转灯壳；
- 聚光灯的 `target` 是独立对象，必须加入 `tank`，否则旋转时 target 留在世界原点；
- 不要用相机的朝向驱动灯，灯是缸的一部分。

## 5. 制作灯体

### 5.1 建模顺序

推荐从“承重结构 → 灯头 → 发光面 → 光域 → 灯光”的顺序做：

1. **立柱/夹具**：先确认灯能站在缸上，不穿玻璃、不穿水面；
2. **横臂/吊线**：连接立柱和灯头，粗细与灯头匹配；
3. **灯头外壳**：长条灯用圆角盒体，避免锐利塑料感；
4. **灯管/柔光板**：比外壳略窄、略内缩，形成真实边缘；
5. **光域**：按灯管尺寸生成，不要凭感觉放大；
6. **聚光灯**：从灯管下表面照向缸内目标。

### 5.2 灯体材质

当前灯体使用：

```js
const lampMat = new THREE.MeshStandardMaterial({
  color: 0x414b43,
  roughness: 0.34,
  metalness: 0.75,
});
```

建议：

- 金属灯体：`metalness 0.65–0.85`，`roughness 0.25–0.45`；
- 黑色哑光：`metalness 0.15–0.35`，`roughness 0.55–0.75`；
- 白色塑料：`metalness 0`，`roughness 0.45–0.65`；
- 灯管：独立的 `MeshStandardMaterial`，设置 `emissive` 和 `emissiveIntensity`，不要和灯体共用材质。

灯管颜色建议偏暖白：

```js
const bulbMat = new THREE.MeshStandardMaterial({
  color: 0xfff4d2,
  emissive: 0xffe5b0,
  emissiveIntensity: 2,
  roughness: 0.3,
});
```

自发光强度在动画循环里由 `light` 控制，初始值只是静态预览值。

### 5.3 灯体不要遮挡水面动画

- 灯头底部应高于缸口，至少留 3–5 cm；
- 灯臂不要穿过水面，否则旋转时会出现“灯臂插在水里”的穿帮；
- 如果灯罩有向下延伸的裙边，确保它不会进入水面波动范围；
- 灯体可以参与射线检测，但不要把它标成 `water` 或 `glass`，否则会抢占交互。

### 5.4 圆角与细节

灯头是近景最容易露馅的地方。建议：

- 外壳用 `RoundedBoxGeometry`，圆角半径约为厚度的 1/4；
- 灯管比外壳短 3–5 mm，形成内缩；
- 灯头两端加轻微倒角，避免纯直角；
- 灯臂与灯头连接处加一个小接头，不要直接悬空相交；
- 金属件不要全是镜面，保留一点粗糙度，否则在深色背景上像塑料。

## 6. 光域：长条灯不能再用圆锥

### 6.1 为什么圆锥会穿帮

`ConeGeometry` 的几何轮廓是“一个顶点 + 一个圆底”。从侧面看，它就是三角形。射灯用它合理，长条灯用它会直接暴露：

- 光域上端收成一个点，而真实灯管是一条线；
- 俯视时光域是圆形，不是长条形；
- 旋转鱼缸时，三角形的斜边会扫过画面，非常显眼。

当前版本已经把圆锥替换为**四边截锥**：上端接近灯管长度，下端略宽，四周和两端做透明度衰减。

### 6.2 推荐几何

当前实现：

```js
const beamGeo = new THREE.CylinderGeometry(1, 1.8, 1, 4, 1, true);
beamGeo.rotateY(Math.PI / 4);
mesh(beamGeo, beamMat, [0.035, 0.201, 0.018], [0.16, 0.31, 0.024]);
```

解释：

- `radialSegments = 4`：四边，不是圆；
- `rotateY(Math.PI / 4)`：让四个面正对前后左右，形成长条截面；
- `scale x = 0.16`：控制灯管方向的长度；
- `scale z = 0.024`：控制前后厚度；
- 上半径 `1`、下半径 `1.8`：光域向下略微扩散；
- `openEnded = true`：不要封口，避免出现上下两块硬面。

### 6.3 参数换算

如果灯管长度改变，不要只拉伸灯壳而忘了光域。按实际灯管尺寸换算：

```text
beamScaleX ≈ 灯管长度 × 0.70
beamScaleZ ≈ 灯管厚度 × 0.86
beamTopY   ≈ 灯管下表面
beamBottomY ≈ 水面下方 0.06–0.08 m
```

例如当前灯管长 `0.227 m`，光域 X 缩放约 `0.16`；这不是精确物理值，而是经过视觉调整的柔和体积。目标是“光从灯管下方展开”，不是让几何边缘与灯管严丝合缝。

### 6.4 光域着色器

当前光域使用自定义 shader，核心是两侧和上下端淡出：

```glsl
float sideFade = pow(max(0., sin(fract(vUv.x * 4.) * 3.14159265)), 2.);
float endFade = smoothstep(0., .18, vUv.y)
              * (1. - smoothstep(.82, 1., vUv.y));
gl_FragColor = vec4(1., .86, .56, sideFade * endFade * .04 * strength);
```

要点：

- `fract(vUv.x * 4.)`：四个侧面分别淡出，避免每个面出现硬边；
- `endFade`：上下端都淡出，避免截锥的顶部/底部形成硬切；
- 颜色偏暖白，和灯管一致；
- alpha 很低（约 `0.04 × strength`），只做“空气中有光”的暗示，不承担照明；
- 不要给光域加 `depthWrite`，否则会遮挡鱼和底砂。

### 6.5 双头灯与多灯头

如果做双头灯：

- 每个灯头各自建一个 beam mesh；
- 每个灯头各自有一个 `SpotLight`，并各自 `tank.add(spot, spot.target)`；
- 两束光域在中间重叠时，降低单束 alpha，避免中间过曝；
- 不要用一盏聚光灯照两个灯头，否则光影方向对不上。

### 6.6 圆管灯

圆管灯的光域不要直接用方截锥。可以用：

- 扁圆柱（`CylinderGeometry` 多段）作为柔光体积；
- 或者仍用四边截锥，但把 `beamScaleZ` 调小，让截面接近扁椭圆；
- 灯管本身用圆柱几何，自发光材质保持一致。

## 7. 灯光状态与动态接线

### 7.1 保留 `light` 平滑变量

不要直接用 `dark` 或 `lightTarget` 控制强度，否则切换主题会瞬间跳变。保留：

```js
light += ((lightTarget ? 1 : 0) - light) * 0.13;
```

`0.13` 是当前过渡速度；改成新灯后可以调，但不要变成 1（无过渡）或过小（开灯太慢）。

### 7.2 四个必须同步的输出

```js
spot.intensity = light * SPOT_MAX;
bulbMat.emissiveIntensity = BULB_MIN + light * BULB_RANGE;
beamMat.uniforms.strength.value = light * (dark ? DARK_BEAM : LIGHT_BEAM);
causticMat.uniforms.uStrength.value = base + light * gain;
```

当前取值：

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| `SPOT_MAX` | `0.44` | 聚光灯最大强度 |
| `BULB_MIN` | `0.08` | 关灯时灯管的微弱底光 |
| `BULB_RANGE` | `2.6` | 灯管自发光增量 |
| `DARK_BEAM` | `0.85` | 深色下光域强度 |
| `LIGHT_BEAM` | `0.28` | 浅色下光域强度 |

这些值不是物理单位，而是经过 tone mapping 和场景曝光调过的视觉参数。换灯后如果灯更亮，不要直接按比例翻倍；先看深色和浅色截图，再微调。

### 7.3 聚光灯参数

当前：

```js
const spot = new THREE.SpotLight(0xffe8be, 0.6, 1.3, Math.PI / 3.3, 0.7, 2);
spot.position.set(0.035, 0.351, 0.018);
spot.target.position.set(0, 0.05, 0);
spot.castShadow = true;
spot.shadow.mapSize.set(1024, 1024);
spot.shadow.camera.near = 0.02;
spot.shadow.camera.far = 1;
spot.shadow.bias = -0.00015;
```

| 参数 | 建议 |
| --- | --- |
| `angle` | 长条灯可用 `Math.PI / 3.3`；小射灯可收窄到 `Math.PI / 4` |
| `penumbra` | `0.5–0.8`，边缘更柔 |
| `decay` | 保持 `2`，符合距离衰减 |
| `distance` | 覆盖到缸底即可，通常 `1.0–1.5` |
| `shadow.mapSize` | 1024 足够；省电模式关闭阴影 |
| `shadow.bias` | 出现条纹时小幅调整，不要一次改太大 |

### 7.4 开灯/关灯过渡

`setLighting(isDark, on)` 只更新状态，实际亮度在 `animateMaterials()` 里平滑。新灯如果有独立灯罩、反光板或第二光源，也要用同一个 `light` 驱动，避免不同步。

### 7.5 交互命中

灯体可以加入 `hitObjects` 并标记为 `'lamp'`，用于光标反馈或未来点击灯具。不要标记成 `'glass'` 或 `'water'`，否则会抢占玻璃敲击和水面投食。

当前灯体的 `blockers` 数组保留了灯杆/灯臂/灯头/灯管的引用，便于将来做遮挡或交互过滤；新增灯体时把主要承光部件也加入同一套管理。

## 8. 焦散与水面波动的关系

### 8.1 当前“光照随水波”的实际含义

当前版本不是逐帧做真实折射，而是：

```text
sim.time ──→ causticMat.uTime ──→ 底砂上的动态光斑
light ────→ causticMat.uStrength ──→ 亮灯时焦散更明显
waterGeo ─→ 水面几何波动 ──→ 水面高光和轮廓变化
```

所以“顶部光照随水波动的照射效果”由两部分共同构成：

1. **水面自身**：几何顶点起伏 + 法线重算，产生移动高光；
2. **底砂焦散**：程序化纹理随时间移动，模拟光经过水面后的聚焦。

这两者都不需要把灯真的跟随每个水面顶点。不要为了“更物理”把灯光逐帧绑到水波上，计算量大且容易闪烁。

### 8.2 换灯后必须保留的接线

- `causticMat.uniforms.uTime.value = sim.time`；
- `causticMat.uniforms.uStrength.value` 继续受 `light` 和 `dark` 影响；
- 聚光灯目标仍指向缸内，不要因为换灯头而让光只照水面；
- 灯管自发光和光域强度仍受同一个 `light` 控制。

### 8.3 多灯头的焦散

如果使用双头灯，可以：

- 保持一张共享焦散面，只提高整体强度；
- 或做两张错位的低强度焦散，模拟两个光斑重叠；
- 不要简单把强度乘 2，否则底砂会过曝。

## 9. 验收清单

### 9.1 外形

- [ ] 灯架有实际支撑，不悬空；
- [ ] 灯头没有穿进水面或玻璃；
- [ ] 灯管比灯头略内缩，近景没有“贴纸感”；
- [ ] 圆角、接头、灯臂比例自然；
- [ ] 深色背景下没有过亮的塑料高光。

### 9.2 光域

- [ ] 长条灯下方没有三角形/圆锥轮廓；
- [ ] 光域方向与灯管长轴一致；
- [ ] 光域边缘柔和，没有硬切或明显四边柱；
- [ ] 双头灯的重叠区没有过曝；
- [ ] 关灯后光域完全消失，不残留灰雾。

### 9.3 照明

- [ ] 深色主题自动亮灯；
- [ ] 手动关灯后灯管、聚光灯、光域、焦散同步变暗；
- [ ] 底砂有明显的由上而下的光池；
- [ ] 鱼和水面有受光高光，不是平光；
- [ ] 阴影没有明显条纹、漂浮或漏光。

### 9.4 动态与性能

- [ ] 旋转鱼缸时灯和光域一起转；
- [ ] 水面波动时焦散持续变化，不冻结；
- [ ] 开灯/关灯平滑过渡，不跳变；
- [ ] 标准质量下目标 60 FPS；
- [ ] 连续开关插件后 GPU 资源不增长；
- [ ] 省电模式下阴影关闭、光域仍正常。

## 10. 常见问题与修复

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 长条灯下有三角形光线 | 还在用 `ConeGeometry` | 换成四边截锥或长条光域 |
| 光域方向与灯管垂直 | 光域没有跟着灯头旋转 | 统一灯头与 beam 的局部轴 |
| 灯亮但场景不亮 | 只设置了灯管自发光，没有聚光灯 | 保留 `SpotLight` 和 target |
| 旋转鱼缸灯不跟着转 | 灯挂在 `scene` | 挂到 `tank`，target 也挂进去 |
| 灯管像灰色塑料 | 没有 emissive 或强度被覆盖 | 检查 `bulbMat.emissiveIntensity` |
| 深色下底砂过曝 | 聚光灯、光域、焦散同时过强 | 先降 `spot.intensity` 和焦散增益 |
| 灯下有硬边光柱 | 光域 alpha 太高、没有边缘淡出 | 降 alpha，补 side/end fade |
| 阴影有条纹 | shadow bias 或 mapSize 不合适 | 微调 `bias`，不要一次改太多 |
| 关灯后还有灰雾 | beam 的 `strength` 没归零或材质残留 | 检查 `light` 乘数 |
| 双头灯中间过亮 | 两束光域叠加 | 降低单束 alpha，错开光斑 |
| 旋转时灯架穿过玻璃 | 灯臂位置没有按新缸尺寸更新 | 重新定锚点，留出干舷 |

### 11.3 最后检查

交付前做一次最简单的判断：

> **把灯关掉，鱼缸应该仍然完整；把灯打开，光应该从灯管的位置向下展开，而不是从灯头中心射出一个圆锥。**

鱼缸可以换，灯也可以换；只要灯仍挂在 `tank` 下、仍由同一个 `light` 驱动、仍把光送进缸内，水波和焦散就会继续工作。
