# P2 红绿灯重制与入缸记录

日期：2026-11-19  
状态：正式入缸，替换银鲦  
流程依据：[鱼种 3D 资产构建指南](guides/鱼种构建指南.md)

## 1. 目标与参考

- 撤下通用低模银鲦，新增 5 条红绿灯（*Paracheirodon innesi*），每条目标体长 4.0 cm。
- 用户参考包括完整侧面、正面和俯视。侧面用于体形与色带，正面用于眼睛/胸鳍和侧扁体积，俯视用于背脊、体宽和尾柄。
- 识别判据：眼后至尾柄的连续蓝绿霓虹带；腹部中后段至尾柄的红色；深背银腹；细长侧扁身体；透明感鳍与浅分叉尾鳍。

## 2. 外形重建取舍

1. 第一次同时输入侧面、正面和俯视，生成结果呈深菱形，尾柄/尾鳍不符合参考，未通过“不残缺、不畸形”判据。源文件和预览以 `*-multiview.*` 保留，不入缸。
2. 第二次只使用信息最一致的完整侧面重建，正面和俯视转为四角度人工对照。结果恢复细长侧扁轮廓、完整浅分叉尾鳍和正确色带。
3. 原始 GLB/OBJ/ZIP、预览、参考图和两次生成记录均保存在 `scripts/neon-tetra/source/`。正式资产由 `scripts/neon-tetra/polish_photo.py` 可复现生成。

### 坐标问题与修复

源 GLB 的几何局部 `-Z` 是背向，节点上另有 90° X 旋转。若直接按局部 Y 分区，会把体厚轴当作背腹轴，导致背鳍颜色落入躯干。正式资产先烘焙节点旋转，使局部坐标统一为：X 吻端→尾端、Y 背腹、Z 左右。`facing: -1` 让最终头朝世界 +X，与游动方向一致。

## 4. 分区与材质

`src/neon-tetra.js` 使用独立阈值，不复制小丑鱼分区。最终顶点数：

| 区域 | 顶点数 |
| --- | ---: |
| 身体 | 4,556 |
| 背鳍 | 273 |
| 臀鳍 | 383 |
| 尾鳍 | 881 |
| 胸鳍 | 299 |
| 腹鳍 | 127 |

胸鳍初版阈值过宽，误染体侧；收紧体轴/背腹窗口并提高侧向阈值后，蓝色集中在鳃后两侧小鳍。所有鳍根权重从 0 平滑增加，胸鳍绕左右镜像枢轴划水，尾鳍滞后于尾柄。

材质保留原照片贴图，只对青色霓虹带、红色后段与固定中性高光做局部校正；不把整条鱼乘成蓝色或红色。单网格限制仍在：鳍不能与身体使用完全不同的透明材质，目前以较低调的鳍膜明度模拟透明感。
