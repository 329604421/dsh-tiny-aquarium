# 定制鱼群

> 前置：先读完 `tinyfish-custom-core`。
> 细则底稿：`<ROOT>/docs/guides/鱼种构建指南.md`（九步全流程、参考图筛选、贴图校正都在里面）

---

## 1. 一条定制鱼的交付标准

| 项 | 要求 |
| --- | --- |
| 网格 | **单网格连通**、法线朝外、无游离碎块、UV 完整不重叠 |
| 贴图 | 颜色贴图内嵌（≤1024²），可选法线；不要外链 `uri` |
| 朝向 | **吻端朝 -X、背朝 +Y**（或在 `params.axis` / `params.facing` 里声明） |
| 动画 | **不要带动画剪辑**。泳姿由引擎的顶点行波驱动，两者叠加会双倍变形 |
| 体长 | 由 `params.targetLength`（米）决定，资产自身单位随意，引擎按最长边归一化 |
| 面数 | ≤ 30000；同屏数量 × 面数决定帧率，2 条以内的英雄鱼可以 20k，群游鱼建议 6k 以内 |

每条鱼必须有独立模型与独立行为参数。**不要用红绿灯或小丑鱼的模型换色冒充新鱼种。**

---

## 2. 参考图怎么要

| 视角 | 用途 | 硬要求 |
| --- | --- | --- |
| 正侧面 | 体形、头身比、色带位置、鳍轮廓 | 鱼体完整，长边 ≥ 800 px |
| 3/4 斜前 | 头部体积、身体厚度、胸鳍着生点 | 眼睛、嘴、鳃盖清楚 |
| 正面 / 俯视 | 体宽、左右对称、背鳍走向 | 不要严重透视畸变 |

3～8 张同一条鱼、光照一致、背景干净。**参考图只能由用户拖进会话**，你不能自己下载。

## 3. 制作步骤

1. **先确认四项**：鱼名、成体体长（cm）、期望数量、是否群游。四项没齐就先问，不要开工。
2. 多视角重建 → 得到单网格 + 颜色贴图（+ 可选法线）。
3. 清理：合并成单网格、去掉内部面、法线重算朝外、UV 展开、贴图烘焙成一张。
4. **缸内二次校色**：贴图里烘焙的高光会让鱼入缸后发白。把颜色压到 sRGB 中等亮度、
   高光留给引擎；对照内置红绿灯与小丑鱼的亮度做一次肉眼比对。
5. 朝向校正：吻端 `-X`、背 `+Y`；如果资产不是这个朝向，在 `params.axis` 里写清楚，
   并说明 `facing` 是 `-1`（头朝体长负端）还是 `1`。
6. 导出 `.glb`（静态、无动画），放到 `assets-src/models/fish/<slug>.glb`。
7. 体检 → 登记 → 构建：

```bash
cd <ROOT>
node scripts/custom-asset.mjs audit --id fish.<slug> --file assets-src/models/fish/<slug>.glb \
  --params '{"targetLength":0.06,"count":2,"cruise":0.6,"rig":"smooth","textured":true}'
node scripts/custom-asset.mjs add --id fish.<slug> --file assets-src/models/fish/<slug>.glb \
  --display-name "红白锦鲤" --license CC0-1.0 --author 我 \
  --params '{"targetLength":0.06,"count":2,"cruise":0.6,"rig":"smooth","textured":true}'
npm run build
```

8. 让用户重启 DSH，在定制页「外观与手感 → 鱼群」里把新鱼种的子条目点「加入缸里」。

## 4. 行为参数（清单 `params`）

| 字段 | 区间 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `targetLength` | 0.02–0.12（米） | 0.05 | 成体体长；越大越容易撞玻璃 |
| `count` | 1–6 | 2 | 同种数量；总鱼数建议 ≤ 12 |
| `cruise` | 0.4–1.2 | 0.7 | 巡航速度系数；小型群游鱼 0.8 左右 |
| `heightBase` | 0.03–0.2（米） | 0.1 | 主要活动水层 |
| `heightStep` | 0.01–0.06 | 0.03 | 个体之间的水层错位，避免排队 |
| `rig` | `smooth`（默认） | — | 非 `clownfish` / `neon-tetra` 时走通用路径 |
| `textured` | `true` | `true` | 用资产自带贴图；`false` 会退回程序化鱼皮（不建议） |
| `facing` | `-1` / `1` | `-1` | 吻端在体长轴哪一端 |

## 5. 验收

```bash
node scripts/custom-asset.mjs audit --id fish.<slug>
npm run build && npm run smoke
```

人工确认（在鱼缸里看 30 秒）：

- [ ] 鱼体朝向正确，不会倒着游或侧躺；
- [ ] 摆尾连续、没有抽搐或双倍变形；
- [ ] 不穿玻璃、不穿石木、不钻进砂里；
- [ ] 投喂时能发现颗粒、接近、吃食，吃空后散开；
- [ ] 敲击玻璃时受惊、急逃、平复，之后回到正常巡游；
- [ ] 与内置两种鱼同缸时，大小比例合理。

## 6. 常见错误

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 鱼倒着游 | 吻端在 `+X` 却按默认 `facing: -1` 导入 | 改朝向，或写 `params.facing: 1` |
| 鱼像被拉扯 | 网格不连通 / 多材质分段 | 合并单网格，贴图烘焙成一张 |
| 摆尾双倍变形 | 资产带 `Swim` 动画，又叠加顶点行波 | 删掉动画剪辑，导出静态网格 |
| 鱼体发白 | 贴图里烘焙了高光 | 压暗贴图，高光留给引擎 |
| 入缸后看不见 | 贴图没内嵌 / 没有 UV | 内嵌 baseColor，展开 UV |
| 鱼撞玻璃 | `targetLength` 或 `count` 太大 | 缩小体长或减数量 |
| 鱼挤成一条线 | `heightStep` 为 0 | 给个体留水层错位 |
