# 定制缸体（外壳）

> 前置：先读完 `aquarium-custom-core`。路径、单位、清单字段、构建、体检、回退都在那一份里。
> 细则底稿：`<ROOT>/docs/guides/鱼缸3D资产制作指南.md`

---

## 1. 你只做「壳」，不做「水」

鱼缸在插件里同时承担四件事：**视觉外壳、模拟容器、交互表面、动画载体**。定制只替换第一件。

运行时由引擎固定提供、**不要在你的 `.glb` 里重复实现**：

| 引擎已有 | 位置 | 说明 |
| --- | --- | --- |
| 可变形水面 | `waterY = 0.267 m` | 逐帧改顶点，旋转时产生波动 |
| 平坦的水面命中面 | 水面下方 2 mm | 投喂射线打在这里 |
| 前玻璃敲击面 | Z ≈ +0.125 m | 单击玻璃的水圈与鱼群受惊 |
| 底砂、砂砾、石子 | Y ≈ 0.015–0.018 m | 已有程序化底砂 |
| 动态焦散 | 砂面上方 | 跟随灯光与时间 |
| 水体色调壳体 | 水面以下 | 背向透明着色 |

所以你的 GLB 里**不要有**：水面平面、底砂、鱼、灯、气泡。只交玻璃、边框、缸口、底座这类外壳件。

---

## 2. 尺寸契约（不得改动）

| 项目 | 数值 | 容差 |
| --- | --- | --- |
| 外框 | 40（X）× 30（Y）× 25（Z）cm | ±5% |
| 内壁可用水体 | X ±19.3、Z ±11.8 cm | 不得缩到比这更小 |
| 水面 | Y = 26.7 cm | 固定 |
| 干舷 | 水面到缸口 ≈ 3.3 cm | 建议保留，水不要平到玻璃上沿 |
| 缸壁厚 | 2～4 mm | 玻璃片 |

**允许改**：圆角、弧面、圆柱、六角、异形、缸口加不加框、玻璃颜色与厚薄、底座材质与轮廓、
缸盖与灯架的造型。**不允许改**：内部可用水体的范围、水面高度、敲击面位置。

原因很直接：鱼的可游动范围、投喂落点、敲击判定都写死在这组数值上。你要一个「看起来更高」的缸，
就把外壳做高、水体照旧——多出来的部分是空气，不是水。

---

## 3. 制作步骤

1. **先算尺寸再建模**。列一张表：外框、内壁、玻璃厚度、缸口高度、底座高度、圆角半径。
   把这张表发给用户确认，再动手。
2. 建模。建议结构：
   - `Glass`：4 片（或曲面的）玻璃，材质 `transparent`、`opacity 0.04–0.09`、`roughness ≤ 0.06`、
     `ior 1.5`、`side: DoubleSide`；
   - `Edge`：玻璃厚度边、角柱、缸口框，金属或半透明浅色；
   - `Base`：底座，不要超过外框；
   - 缸盖/灯架如需保留，挂在 `+Y`，不要侵入水面以下。
3. 原点放在**缸底中心**，`forward = +Z`（正面朝 +Z）。不要加旋转、不要加缩放。
4. 贴图内嵌，颜色贴图 ≤ 1024²；玻璃尽量不要贴图，用材质参数。
5. 导出单个 `.glb`（米制），放到 `assets-src/models/tank/<slug>.glb`。
6. 体检 → 登记 → 构建：

```bash
cd <ROOT>
node scripts/custom-asset.mjs audit --id tank.<slug> --file assets-src/models/tank/<slug>.glb
node scripts/custom-asset.mjs add --id tank.<slug> --file assets-src/models/tank/<slug>.glb \
  --display-name "复古圆角缸" --license CC0-1.0 --author 我
npm run build
```

7. 告诉用户：**重启 DSH**，然后在定制页「外观与手感 → 缸体」一行右侧的下拉里选中新缸体。

## 4. 验收

自动（必须贴原始输出）：

```bash
node scripts/custom-asset.mjs audit --id tank.<slug>
npm run build
npm run smoke
```

人工（在鱼缸里看，至少确认四条）：

- [ ] 玻璃没有插进水面以下形成「水下多一层壁」；
- [ ] 左右拖动时水面仍在晃，水波不会被外壳挡住；
- [ ] 点前玻璃有敲击光圈，点水面能投喂，颗粒落到砂面；
- [ ] 深浅色主题下玻璃边缘都还能看出轮廓，不是一团灰。

## 5. 常见错误

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 缸看起来「浮」在桌上 | 底座没做，或原点不在缸底 | 原点归到缸底中心，补底座 |
| 鱼一半在玻璃外 | 内壁做小了 | 内壁至少 X ±19.3、Z ±11.8 cm |
| 水面处有一条硬直线 | 你在 GLB 里做了「水线装饰条」 | 删掉，水面由引擎绘制 |
| 玻璃发灰、看不见鱼 | 玻璃 `opacity` 太高或写了 `depthWrite: true` | `opacity ≤ 0.09`、`depthWrite: false` |
| 敲击没反应 | 外壳挡住了前玻璃命中面 | 前玻璃保持 Z ≈ +0.125 m，不要在它前面加板 |
| 整个缸偏大偏小 | 按厘米导出了 | 按米导出（40 cm → 0.40） |
