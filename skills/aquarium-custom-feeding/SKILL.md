# 定制投喂习惯

> 前置：先读完 `aquarium-custom-core`。
> 细则底稿：`<ROOT>/docs/guides/投喂习惯与动作制作指南.md`

---

## 1. 这个维度不产出模型，只产出一组参数

投喂习惯是**行为参数预设**：鱼发现食物的快慢、抢同一粒的半径、吃空后散开多久、被敲缸后逃多久、
多久平复。它写进 `presets.json`，不涉及任何 `.glb`。

不可改的业务规则（改了就破坏验收，体检之外还有单测兜底）：

- 每次投喂 **4 粒**；鱼食队列上限 **100 粒**；两次投喂最小间隔 **150 ms**；
- 颗粒 **25 秒**未被吃则自然淡出；
- 吃食判定是**原子消费**：同一粒只会被一条鱼吃掉；
- **受惊优先于觅食**，受惊期间释放食物占用，平复后要能回到剩余颗粒；
- 动作只能用速度、加速度、转向与缓动构成，**不许直接改坐标**。

---

## 2. 九个可调参数

| 键 | 区间 | 缺省 | 观感 |
| --- | --- | --- | --- |
| `noticeMin` | 0.1–1.6 s | 0.25 | 最近的鱼多久发现食物（下限） |
| `noticeMax` | 0.3–2.5 s | 1.0 | 最远的鱼多久发现食物（上限） |
| `competeRadius` | 0.02–0.10 m | 0.055 | 进入「争抢」状态的半径，越大越挤 |
| `scatterMin` | 1.2–7 s | 3.2 | 吃空后最短散开时长 |
| `scatterMax` | 1.6–9 s | 4.6 | 最长散开时长 |
| `fleeMin` | 0.2–2 s | 0.55 | 敲缸后最短急逃时长 |
| `fleeMax` | 0.3–2.5 s | 0.9 | 最长急逃时长 |
| `settleMin` | 0.4–3.5 s | 1.25 | 最短平复时长 |
| `settleMax` | 0.6–4 s | 1.85 | 最长平复时长 |

约束：每对 `min ≤ max`，越界或写反一律回退默认值并在体检里报出来。

---

## 3. 三种口味（可直接套用）

| 口味 | notice | compete | scatter | flee | settle | 感觉 |
| --- | --- | --- | --- | --- | --- | --- |
| 悠闲 | 0.6 / 1.8 | 0.04 | 5 / 7 | 0.5 / 0.8 | 1.6 / 2.4 | 慢半拍、吃散得开，适合长时间看 |
| 标准 | 0.25 / 1.0 | 0.055 | 3.2 / 4.6 | 0.55 / 0.9 | 1.25 / 1.85 | 与内置一致 |
| 饿疯了 | 0.12 / 0.5 | 0.085 | 2 / 3 | 0.4 / 0.6 | 0.8 / 1.2 | 一投就冲、挤成一团、惊一下马上回来 |

## 4. 步骤

1. 先问用户三件事：**想要什么手感**（一句话）、**不能接受什么**（例如「不要抢不到食」）、**新预设的中文名**。
2. 把上面那张表里对应的区间抄成一次改动，**只改需要的那几项**，其余保持缺省。
3. 体检 → 登记：

```bash
cd <ROOT>
node scripts/custom-asset.mjs audit --id feeding.<slug> \
  --params '{"noticeMin":0.12,"noticeMax":0.5,"competeRadius":0.085,"scatterMin":2,"scatterMax":3,"fleeMin":0.4,"fleeMax":0.6,"settleMin":0.8,"settleMax":1.2}'
node scripts/custom-asset.mjs add --id feeding.<slug> \
  --display-name "饿疯了" --license CC0-1.0 --author 我 \
  --params '{"noticeMin":0.12,...}'
npm run build
```

4. 让用户重启 DSH，在定制页「外观与手感 → 投喂习惯」一行右侧的下拉里选中。

## 5. 验收

```bash
node scripts/custom-asset.mjs audit --id feeding.<slug>
npm test            # feeding / startle 单测
npm run build && npm run probe:feeding
```

人工确认（投一次食 + 敲一次缸）：

- [ ] 近的鱼先动、远的鱼明显滞后，但 **2.5 秒内全部有反应**；
- [ ] 有争抢但不卡死：同一粒被抢走后，失手的鱼会盘旋再找下一粒；
- [ ] 4 粒在 25 秒内被吃完（或自然淡出），不会留下永远吃不掉的颗粒；
- [ ] 吃空后分批散开，不是整齐地一起转身；
- [ ] 抢食中敲缸 → 先逃，平复后回到剩余颗粒。

---

## 6. 常见错误

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 鱼完全不理食 | `noticeMax` 太大或写成了 0 | 检查区间，缺省 0.25 / 1.0 |
| 全部挤在一粒上 | `competeRadius` 太大 | 降到 0.04–0.06 |
| 吃完不散开 | `scatterMax` 太小 | 回到 3.2 / 4.6 附近 |
| 敲缸后长时间发呆 | `settleMax` 太大 | 降到 2 秒以内 |
| 参数没生效 | 没选中该预设，或没重启 | 定制页确认选中 + 重启 DSH |
| 体检报「乱序」 | `min` > `max` | 两值对调 |
