# 定制灯具

> 前置：先读完 `tinyfish-custom-core`。
> 细则底稿：`<ROOT>/docs/guides/鱼缸顶灯3D资产制作指南.md`

---

## 1. 灯不是「一个会发光的模型」，是四件东西

| 部件 | 谁来负责 | 你不能丢的接线 |
| --- | --- | --- |
| 灯体网格 | **你** | 挂在缸体局部坐标上，跟着缸一起转 |
| 灯管自发光 | 引擎 | 节点名含 `Bulb` / `Tube` / `Glow` 的网格会被换成自发光材质，随开灯变亮 |
| 真实照明 | 引擎 | `SpotLight`，位置/角度/色温/亮度来自清单 `params` |
| 可见光域 | 引擎 | 柔和光束几何，随深浅色主题变化 |

所以你的 GLB **只交灯体**：灯杆、灯臂、灯头、灯罩、卡扣。不要在里面放光源、不要做可见光束几何、
不要烘焙「灯照在墙上」的效果。

---

## 2. 挂点与坐标

- 坐标系与缸体相同：**米制、Y 向上、缸底中心为原点、+Z 朝前**。
- 灯挂在缸口**后侧上方**，通常从 `Z ≈ -0.15 m` 起竖，臂伸到 `X ≈ 0.03`、`Z ≈ 0.02` 的灯头位置。
  （内置夹灯：立柱 `(0.15, 0.184, -0.146)`、灯头 `(0.035, 0.366, 0.018)`，可直接对齐这套骨架。）
- 灯头底面离水面 **8～12 cm**（即 Y ≈ 0.35–0.39 m）。太低会照出硬边、太高高光散掉。
- 灯体任何部分**不得进入水面以下**（Y < 0.267 m）；夹爪可以夹在缸口，但要贴住玻璃外侧。
- 原点放在**缸口后侧与缸体的接触点**更省事；如果原点放在灯头中心，请在清单 `params.pivot` 里说明，
  并在回报里写清楚——否则灯会整块偏移。

## 3. 清单参数（决定灯怎么亮）

```json
"params": {
  "colorTemp": 4200,
  "intensity": 1,
  "angle": 0.95,
  "penumbra": 0.7,
  "target": [0, 0.05, 0]
}
```

| 字段 | 区间 | 说明 |
| --- | --- | --- |
| `colorTemp` | 2700–6500 K | 暖白 → 冷白；会同时影响聚光灯颜色与灯管自发光 |
| `intensity` | 0.3–2 | 1 = 与内置夹灯同等亮度 |
| `angle` | 0.5–1.15 rad | 光域张角；长条灯取大值，射灯取 0.5–0.7 |
| `penumbra` | 0.1–0.9 | 边缘柔化，越大越柔 |
| `target` | `[x,y,z]`（米） | 默认 `[0, 0.05, 0]`，照向水面前中部 |

## 4. 制作步骤

1. 先选灯型：**长条灯 / 圆管灯 / 方吊灯 / 双头夹灯 / 轨道灯**。灯型决定光域形状，不要做完再改。
2. 建模，命名关键节点：灯管或柔光面必须叫 `Bulb`、`Tube` 或 `Glow`（大小写不敏感），引擎靠名字接线。
3. 材质：金属 `metalness 0.6–0.9`、`roughness 0.25–0.45`；灯罩内侧可用浅色漫反射。
   灯管本体不用贴图，材质由引擎覆盖。
4. 导出单个 `.glb`（米制），`forward = -Y`（灯头朝下），放到 `assets-src/models/lamp/<slug>.glb`。
5. 体检 → 登记 → 构建：

```bash
cd <ROOT>
node scripts/custom-asset.mjs audit --id lamp.<slug> --file assets-src/models/lamp/<slug>.glb
node scripts/custom-asset.mjs add --id lamp.<slug> --file assets-src/models/lamp/<slug>.glb \
  --display-name "黄铜吊灯" --license CC0-1.0 --author 我 \
  --params '{"colorTemp":3000,"intensity":1.1,"angle":0.9,"penumbra":0.75}'
npm run build
```

6. 让用户重启 DSH，在定制页「外观与手感 → 灯具」一行右侧的下拉里选中。

---

## 5. 验收

```bash
node scripts/custom-asset.mjs audit --id lamp.<slug>
npm run build && npm run smoke
```

人工确认：

- [ ] 深色主题下自动亮灯，灯管亮、场景也亮（不是只有灯壳亮）；
- [ ] 切「常灭」后灯管熄灭、光域消失，但灯体轮廓仍可辨认；
- [ ] 左右拖动时灯跟着缸一起转，光束不横向错位；
- [ ] 灯照到砂面的光斑仍在缸内，不会打到缸外墙上；
- [ ] 灯体不穿玻璃、不漏到水面以下。

## 6. 常见错误

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 灯亮但场景不亮 | 只在 GLB 里做了自发光 | 让引擎的聚光灯接管：确认 `params` 里 `intensity` 不为 0 |
| 长条灯下出现圆锥 | 光域张角用了射灯值 | `angle` 调到 0.9–1.1，`penumbra` 0.7 以上 |
| 灯悬空 / 偏一大截 | 原点不在挂点 | 原点归到缸口后侧接触点，或说明 `params.pivot` |
| 转动时灯不跟着走 | 导出时把灯挂在世界坐标 | 原点与轴向按缸体局部坐标重导出 |
| 灯管一直是黑的 | 节点没叫 `Bulb`/`Tube`/`Glow` | 改节点名 |
| 灯照出硬边方框 | 灯罩没有开口，或灯头太低 | 抬高灯头，加柔光面 |
